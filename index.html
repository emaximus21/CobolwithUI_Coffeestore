                       WITH NO ADVANCING

                   IF PRODUCT-CHOICE < 1 OR PRODUCT-CHOICE > 3
                       DISPLAY "Invalid choice. Enter 1, 2, or 3."
                   END-IF
               END-PERFORM
               EVALUATE PRODUCT-CHOICE
                   WHEN 1
                       MOVE "ESPRESSO MACHINE" TO ITEM-NAME
                       MOVE 18500 TO UNIT-PRICE-CENTS
                       MOVE ESPRESSO-STOCK TO STOCK-AVAILABLE
                   WHEN 2
                       MOVE "CERAMIC MUG" TO ITEM-NAME
                       MOVE 1250 TO UNIT-PRICE-CENTS
                       MOVE MUG-STOCK TO STOCK-AVAILABLE
                   WHEN 3
                       MOVE "COFFEE BEANS" TO ITEM-NAME
                       MOVE 1600 TO UNIT-PRICE-CENTS
                       MOVE BEANS-STOCK TO STOCK-AVAILABLE
               END-EVALUATE
               IF STOCK-AVAILABLE = ZERO
                   DISPLAY "SOLD OUT. Choose another product."
               ELSE
                   MOVE ZERO TO ORDER-QUANTITY
                   PERFORM UNTIL ORDER-QUANTITY > ZERO
                       AND ORDER-QUANTITY <= STOCK-AVAILABLE
                       DISPLAY "Quantity (max " STOCK-AVAILABLE "): "
                           WITH NO ADVANCING
                       ACCEPT ORDER-QUANTITY
                       IF ORDER-QUANTITY = ZERO
                           DISPLAY "Enter a quantity greater than zero."
                       ELSE
                           IF ORDER-QUANTITY > STOCK-AVAILABLE
                               DISPLAY "Not enough stock. Try again."
                           END-IF
                       END-IF
                   END-PERFORM
                   COMPUTE ORDER-TOTAL-CENTS =
                       ORDER-QUANTITY * UNIT-PRICE-CENTS
                   COMPUTE STOCK-LEFT =
                       STOCK-AVAILABLE - ORDER-QUANTITY
                   EVALUATE PRODUCT-CHOICE
                       WHEN 1
                           MOVE STOCK-LEFT TO ESPRESSO-STOCK
                       WHEN 2
                           MOVE STOCK-LEFT TO MUG-STOCK
                       WHEN 3
                           MOVE STOCK-LEFT TO BEANS-STOCK
                   END-EVALUATE

                   MOVE ORDER-TOTAL-CENTS TO DISPLAY-TOTAL
                   MOVE STOCK-LEFT TO DISPLAY-STOCK
                   DISPLAY "ORDER ACCEPTED: " ITEM-NAME
                   DISPLAY "QUANTITY: " DISPLAY-QUANTITY
                   DISPLAY "UNIT PRICE (CENTS): " UNIT-PRICE-CENTS
                   DISPLAY "ORDER TOTAL (CENTS): " DISPLAY-TOTAL
                   DISPLAY "STOCK LEFT: " DISPLAY-STOCK
               END-IF

                   WITH NO ADVANCING
               ACCEPT SHOP-ACTIVE
               IF SHOP-ACTIVE NOT = "N"
                   MOVE "Y" TO SHOP-ACTIVE
               END-IF
           END-PERFORM
           DISPLAY "Thanks for visiting Corner Shop."
           STOP RUN.

LOOK FOR THESE WORDS

Five small jobs.

  1. ACCEPTWaits for the student to type a product number or quantity.
  2. EVALUATEChooses the name, price, and stock for product 1, 2, or 3.
  3. PERFORM UNTILRepeats the menu and asks again when the quantity is too large.
  4. COMPUTEWorks out the total and the stock left.
  5. DISPLAYShows the receipt, then the menu shows the updated stock.

02 / SAME SHOP, NEW LAYERS

Now give it a website.

You already understand the checkout rule. The website gives people buttons instead of keyboard prompts.

YOU CLICKUIBasket and order button
→
THE MESSENGERAPINode sends the order
→
THE CHECKERCOBOLStock and total rules
↩
The result comes back to the screen.

UI · what you see
The page shows products. Add to basket changes only the basket.

API · the messenger
Node receives the order and gives COBOL the quantity, price, and current stock.

COBOL · the rule keeper
COBOL approves or rejects the order and returns the calculation. The UI shows the result.

Easy, right? ✨One shop rule, first by typing, then through a website.

03 / YOUR TURN

Ready to explore?

Want to change the code? First make your own copy, then open that copy in an online coding workspace. Everything runs in your browser; no editor to install.

Fork means “make my own copy.” Codespaces is “my coding workspace in a browser.” Pull is for getting updates later; you do not need it to start.

Step 1: Open the project repo ↗

You need a GitHub account. Codespaces usage limits may apply.

</> DO THESE STEPS IN ORDER Fork first. Then open Codespaces. github.com/emaximus21/CobolwithUI_Coffeestore Click to see what to do ↓
  1. On the project page, click Fork (near the top-right), then click Create fork. Now you have your own copy.
  2. Open your new copy. Click Code → Codespaces → Create codespace on main. Do not open Codespaces on the original repo.
  3. Wait for setup to finish. It installs Node and COBOL and builds the COBOL program for you.
  4. In the Codespaces terminal, type npm start.
  5. Open port 4173 when Codespaces offers it, or select it in the Ports tab.

That’s it: the shop is running in your browser, and your code changes belong to your copy.
