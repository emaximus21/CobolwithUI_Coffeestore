FIRST-ORDER.CBL / A TEXT-ONLY SHOP WITH KEYBOARD INPUT
       IDENTIFICATION DIVISION.
       PROGRAM-ID. FIRST-ORDER.
       DATA DIVISION.
       WORKING-STORAGE SECTION.
       01 PRODUCT-CHOICE PIC 9 VALUE ZERO.
       01 ITEM-NAME PIC X(20) VALUE SPACES.
       01 UNIT-PRICE-CENTS PIC 9(5) VALUE ZERO.
       01 STOCK-AVAILABLE PIC 99 VALUE ZERO.
       01 ORDER-QUANTITY PIC 99 VALUE ZERO.
       01 ORDER-TOTAL-CENTS PIC 9(7) VALUE ZERO.
       01 STOCK-LEFT PIC 99 VALUE ZERO.
         01 ESPRESSO-STOCK PIC 99 VALUE 8.
         01 MUG-STOCK PIC 99 VALUE 12.
         01 BEANS-STOCK PIC 99 VALUE 20.
         01 DISPLAY-ESPRESSO-STOCK PIC Z9.
         01 DISPLAY-MUG-STOCK PIC Z9.
         01 DISPLAY-BEANS-STOCK PIC Z9.
       01 DISPLAY-QUANTITY PIC Z9.
       01 DISPLAY-TOTAL PIC Z(6)9.
       01 DISPLAY-STOCK PIC Z9.
         01 SHOP-ACTIVE PIC X VALUE "Y".
       PROCEDURE DIVISION.
           PERFORM UNTIL SHOP-ACTIVE = "N"
             MOVE ESPRESSO-STOCK TO DISPLAY-ESPRESSO-STOCK
             MOVE MUG-STOCK TO DISPLAY-MUG-STOCK
             MOVE BEANS-STOCK TO DISPLAY-BEANS-STOCK
             DISPLAY "CORNER SHOP"
             DISPLAY "1. ESPRESSO MACHINE - 18500 CENTS - STOCK "
               DISPLAY-ESPRESSO-STOCK
             DISPLAY "2. CERAMIC MUG - 1250 CENTS - STOCK "
               DISPLAY-MUG-STOCK
             DISPLAY "3. COFFEE BEANS - 1600 CENTS - STOCK "
               DISPLAY-BEANS-STOCK
             MOVE ZERO TO PRODUCT-CHOICE
             PERFORM UNTIL PRODUCT-CHOICE >= 1
               AND PRODUCT-CHOICE <= 3
               DISPLAY "Choose a product (1-3): "
                 WITH NO ADVANCING
               ACCEPT PRODUCT-CHOICE
               IF PRODUCT-CHOICE < 1 OR PRODUCT-CHOICE > 3
                 DISPLAY "Invalid choice. Enter 1, 2, or 3."
               END-IF
             END-PERFORM
             EVALUATE PRODUCT-CHOICE
               WHEN 1
                 MOVE "ESPRESSO MACHINE" TO ITEM-NAME
                 MOVE 18500 TO UNIT-PRICE-CENTS
                 MOVE ESPRESSO-STOCK TO STOCK-AVAILABLE
               WHEN 2
                 MOVE "CERAMIC MUG" TO ITEM-NAME
                 MOVE 1250 TO UNIT-PRICE-CENTS
                 MOVE MUG-STOCK TO STOCK-AVAILABLE
               WHEN 3
                 MOVE "COFFEE BEANS" TO ITEM-NAME
                 MOVE 1600 TO UNIT-PRICE-CENTS
                 MOVE BEANS-STOCK TO STOCK-AVAILABLE
             END-EVALUATE
             IF STOCK-AVAILABLE = ZERO
               DISPLAY "SOLD OUT. Choose another product."
             ELSE
               MOVE ZERO TO ORDER-QUANTITY
               PERFORM UNTIL ORDER-QUANTITY > ZERO
                 AND ORDER-QUANTITY <= STOCK-AVAILABLE
                 DISPLAY "Quantity (max " STOCK-AVAILABLE "): "
                   WITH NO ADVANCING
                 ACCEPT ORDER-QUANTITY
                 IF ORDER-QUANTITY = ZERO
                   DISPLAY "Enter a quantity greater than zero."
                 ELSE
                   IF ORDER-QUANTITY > STOCK-AVAILABLE
                     DISPLAY "Not enough stock. Try again."
                   END-IF
                 END-IF
               END-PERFORM
               COMPUTE ORDER-TOTAL-CENTS =
                 ORDER-QUANTITY * UNIT-PRICE-CENTS
               COMPUTE STOCK-LEFT =
                 STOCK-AVAILABLE - ORDER-QUANTITY
               EVALUATE PRODUCT-CHOICE
                 WHEN 1
                   MOVE STOCK-LEFT TO ESPRESSO-STOCK
                 WHEN 2
                   MOVE STOCK-LEFT TO MUG-STOCK
                 WHEN 3
                   MOVE STOCK-LEFT TO BEANS-STOCK
               END-EVALUATE
               MOVE ORDER-QUANTITY TO DISPLAY-QUANTITY
               MOVE ORDER-TOTAL-CENTS TO DISPLAY-TOTAL
               MOVE STOCK-LEFT TO DISPLAY-STOCK
               DISPLAY "ORDER ACCEPTED: " ITEM-NAME
               DISPLAY "QUANTITY: " DISPLAY-QUANTITY
               DISPLAY "UNIT PRICE (CENTS): " UNIT-PRICE-CENTS
               DISPLAY "ORDER TOTAL (CENTS): " DISPLAY-TOTAL
               DISPLAY "STOCK LEFT: " DISPLAY-STOCK
             END-IF
             DISPLAY "Shop again? (Y/N, N exits): "
               WITH NO ADVANCING
             ACCEPT SHOP-ACTIVE
             IF SHOP-ACTIVE NOT = "N"
               MOVE "Y" TO SHOP-ACTIVE
             END-IF
           END-PERFORM
           DISPLAY "Thanks for visiting Corner Shop."
           STOP RUN.

Read it in six pieces

1. Program and data. WORKING-STORAGE SECTION keeps stock for all three products. The stock fields live for the full program run, so a sale stays deducted on the next visit to the menu.

2. The shop loop. PERFORM UNTIL SHOP-ACTIVE = "N" repeats the menu and checkout. Enter N to exit; otherwise it returns to the menu.

3. Text input. DISPLAY prints the menu and prompts. ACCEPT reads the product number and quantity typed by the student.

4. Product selection. EVALUATE matches choices 1, 2, or 3, then MOVE selects its name, price, and current stock.

5. Quantity retry. The inner PERFORM UNTIL keeps asking while quantity is zero or larger than stock. An oversold entry does not end the program.

6. Calculation and update. COMPUTE works in cents. A second EVALUATE saves the remaining stock to the selected product before the next menu appears.

Try it: order 2 espresso machines, answer Y, then check the menu shows stock 6. Enter 9 to see the quantity prompt retry, then enter 4. The next menu shows stock 2.

02 / CONNECT IT TO THE SHOP

Same rule, real request

The standalone example gets input from the keyboard with ACCEPT and keeps stock in working storage. In the website, the browser sends basket quantities to Node instead. Node passes quantities, prices, and current stock to backend/shop.cbl; COBOL runs the checkout checks and calculations, and the API returns the result to the UI.

03 / FOLLOW THE LAYERS

How this shop works

Each layer has one clear job.

01 / UI

The browser

index.html, styles.css, and app.js show products and keep basket quantities. Place order sends those quantities to the API; adding to the basket does not change stock.

02 / API

The Node bridge

server.js receives the order, supplies the current price and stock, and runs the compiled COBOL program. It updates inventory only after COBOL approves the whole order.

03 / COBOL

The checkout rules

backend/shop.cbl uses ACCEPT to read order records, PERFORM VARYING to check each product, COMPUTE for the stock and total, and DISPLAY to return the result. It rejects quantities above available stock.

COMPUTE remaining-stock(item-index) =
    item-stock(item-index) - item-quantity(item-index)
COMPUTE total-cents = total-cents +
    item-quantity(item-index) * item-price(item-index)

It returns either an error or the new stock and total. The API uses that result for the receipt.
